# Darts 501 Skill File

## Double Out Rule

All finishes must end on a double. The final dart must be a double (the outer ring of any number) or bullseye (inner bull = 50, outer bull = 25). A finish that does not end on a double is invalid.

## Maximum Checkout

The highest possible score to finish in three darts is 170: T20, T20, Bull (50).

The following remaining scores cannot be finished in three darts: 169, 168, 166, 165, 163, 162, 159.

## Bogey Numbers

A bogey number is a remaining score that cannot be finished in three darts or leaves a difficult finish. The system should avoid suggesting finishes that leave these scores.

**Unfinishable scores** (no three-dart finish): 169, 168, 166, 165, 163, 162, 159

**Difficult leaves** (hard to return to from the prior score):

| If you leave... | After scoring... | Problem |
|-----------------|------------------|---------|
| 171             | 180 from 351     | Cannot finish 171 in 3 darts |
| 169             | 180 from 349     | Cannot finish 169 in 3 darts |
| 173             | 180 from 353     | Cannot finish 173 in 3 darts |
| 175             | 180 from 355     | Cannot finish 175 in 3 darts |
| 176             | 180 from 356     | Cannot finish 176 in 3 darts |
| 178             | 180 from 358     | Cannot finish 178 in 3 darts |
| 179             | 180 from 359     | Cannot finish 179 in 3 darts |

When choosing between two valid finish paths, prefer the path that leaves the best backup score if the first dart misses. The backup score should not be a bogey number.

**Key transitions**: Leaving 170, 167, 164, 161 are good because a 180 leaves a finishable score. Leaving 169, 168, 166, 165, 163, 162, 159 are bad because a 180 leaves an unfinishable bogey.

## Split Preference

A split is a remaining score that has two or more valid double-finish paths. Splits are preferred over single-finish leaves because they give the player options if the first dart misses.

**Examples of splits and their double paths**:

| Score | Available doubles |
|-------|-------------------|
| 32    | D16 or D8         |
| 40    | D20 only          |
| 30    | D15 only          |
| 34    | D17 only          |
| 36    | D18 only          |
| 38    | D19 only          |

Prefer leaving a split (32) over a single-path leave (30) when both are valid options from the prior score. The player can always fall back to the second double if the first misses.

When multiple splits exist at a score, prefer the double that is in the player's preferred zone (typically the 16/20 area for most players).

## Middle Game Strategy

The middle game refers to scoring decisions made when the remaining score is too high to finish in one turn. The goal is to leave a clean setup for a future out shot.

**Principle**: When deciding what to aim for, consider not just the maximum score but what that score leaves behind.

**Example**: At 303, hitting 180 leaves 123 (a valid checkout). However, if the player misses the first treble and hits a single 20, the maximum follow-up is 140, leaving 163 — a bogey number. An experienced player might aim for T18 instead, because a single 18 leaves 230, which sets up a T20 for a 170 leave.

**Key scores to understand**:

- A score that can reach exactly 170 after a 180 is clean. Examples: 350, 330, 310, 290, 270, 250, 230, 210, 190.
- A score that reaches 169, 168, 166, 165, 163, 162, or 159 after a 180 is a bogey leave. These should be avoided.

When the remaining score is in the 200-350 range, prefer scoring routes that leave a clean number. When in doubt, aim for T20 to set up the 170 area.

**High percentage zones**: T20 is the most commonly aimed treble because it sets up the most finish combinations. When no clean finish path is available, T20 is usually the default aim.

## Voice Command Conventions

When the user speaks, the system interprets as follows:

- **Bare number**: The total score of the turn (e.g., "125" = scored 125 this turn)
- **"Single N", "Double N", "Triple N"**: An individual dart. "Triple 20" = one dart worth 60.
- **Mixed input**: If the user reports qualified darts (single/double/triple) AND a bare number in the same utterance, all qualified darts are ignored and only the bare number is treated as the turn score.
- **"New game"**: Resets remaining score to 501 and clears turn history.
- **"Undo last score"**: Restores the previous remaining score and removes the last turn from history.
- **"What's my score?"**: Returns the current remaining score and number of turns played.
- **Bust**: If a reported score would take the remaining score below 0, the system confirms with the user. If confirmed, the remaining score does not change.
- **Invalid score**: If a reported score cannot be achieved with three darts, the system responds that the score cannot be correct.

---

## Response Style

When responding to the player, speak in a conversational tone. Include the current remaining score and suggest three specific darts to throw. Briefly note if the suggested finish leaves a clean backup or is a split.

Example: "You're at 247. I'd suggest T20, T20, and double 5. If you miss the first dart, you'd still have a split leave on 32 — double 16 or double 8 to finish."
